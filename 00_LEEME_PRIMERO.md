# DING59 - Agentic Research Lab #1

## Paquete inicial individual

Este laboratorio enseña a utilizar asistentes de inteligencia artificial como roles científicos controlados. El objetivo no es obtener una respuesta rápida ni programar, sino producir un modelo matemático candidato, comprobarlo y registrar una decisión humana.

## Resultado esperado

Al finalizar tendrás:

1. Tres contratos redactados, probados y versionados.
2. Un problema científico definido sin datos inventados.
3. Un plan y un encargo revisados por vos.
4. Un reporte de modelado generado por el agente.
5. Un modelo matemático consolidado por vos.
6. Un Human Validation Gate con alcance y limitaciones.
7. Un registro de investigación y el inicio del paper.

## Cómo usar el paquete

1. Copiá `plantillas/Trabajo_Estudiante` y renombrala `Lab1_Apellido_Nombre`.
2. Conservá intacta la carpeta `ejemplo_resuelto` para consultarla únicamente como referencia.
3. Seguí `01_INSTRUCCIONES_PASO_A_PASO.md`.
4. Usá los prompts de `03_PROMPTS_PARA_COPIAR.md`.
5. Antes de entregar, completá `04_CHECKLIST_ENTREGA.md`.

> Regla central: la IA puede proponer y comprobar; el estudiante revisa, decide y firma.

## Software

- Editor Markdown: Visual Studio Code recomendado; también sirven Notepad++, Obsidian o cualquier editor de texto.
- Asistente IA: Codex, ChatGPT, Claude, Gemini, Copilot u otro que permita adjuntar o copiar archivos.
- Opcional: Git para conservar versiones.
- No se necesita MATLAB, Python ni un solver en este laboratorio.

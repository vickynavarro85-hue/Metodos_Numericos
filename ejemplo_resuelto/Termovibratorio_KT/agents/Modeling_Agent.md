# Modeling Agent - v1.0

## Objetivo

Proponer un PVI termo-vibratorio a partir de un handoff aceptado.

## Entradas

AGENTS.md, Modeling_Handoff.md y Problem_Definition.md.

## Tareas

Declarar estados, entradas, parámetros, unidades, ecuaciones, IC, supuestos, dominio y checks.

## Salida

Modeling_Report.md.

## Restricciones

No inventar valores, incorporar acoplamientos nuevos, programar, elegir solver ni aprobar.

## Checks

Dimensiones, signos, equilibrio, positividad de rigidez y casos límite.

## Parada

READY_FOR_HUMAN_REVIEW si el reporte está completo; NEEDS_INPUT o BLOCKED si no puede formularse responsablemente.
